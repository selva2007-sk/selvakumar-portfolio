# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/selva2007-sk/selvakumar-portfolio.git
```

## Navigate

```bash
cd selvakumar-portfolio
```

## Install Dependencies

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```

## Production Build

```bash
npm run build
```
